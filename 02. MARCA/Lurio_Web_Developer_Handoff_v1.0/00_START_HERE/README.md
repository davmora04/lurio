# Lurio — Web Developer Handoff v1.0

This package is the implementation handoff for the Lurio launch website.

## Start here
1. Read `04_Design_System/DESIGN_SPEC.md`.
2. Use `05_Website_Copy/WEBSITE_COPY.md` as the approved copy foundation.
3. Follow `06_IA_and_Components/SITEMAP_AND_IA.md`.
4. Build from the supplied logos and optimized web imagery.
5. Use the reference implementation for behavior/layout cues, not as a mandatory technical stack.
6. Review `05_Website_Copy/CONTENT_STATUS.md` before publishing any claims.

## Brand non-negotiables
- Master brand: Lurio.
- Brand idea / leading tagline: Keep Expansion Moving.
- Primary launch geography: Colombia.
- Personality: Resourceful, Approachable, Sharp, Confident.
- Visual territory: Amethyst & Ink.
- Distinctive sophistication: credible at first glance, distinctive on second glance.
- Lurio is not positioned as a law firm, accounting firm, recruitment agency, EOR, or one-stop administrative-services provider.
- Do not make the website look like a SaaS startup or a traditional Big Four imitation.
