# Developer launch checklist

## Brand
[ ] Use supplied wordmark artwork; do not redraw it.
[ ] Amethyst is an accent, not the dominant page background.
[ ] No map/globe/growth-arrow/handshake visual clichés.
[ ] Display font and body font match spec.
[ ] Logo has adequate clear space.

## Content
[ ] Colombia is the launch capability; LATAM is framed as ambition.
[ ] No unverified client logos, testimonials or quantified claims.
[ ] No wording implying Lurio itself provides regulated legal/accounting services.
[ ] All primary CTAs point to a working conversion path.

## Responsive
[ ] 320px minimum viewport tested.
[ ] Tablet and large desktop tested.
[ ] Nav and form keyboard tested.
[ ] Images crop intentionally at each breakpoint.

## Technical
[ ] Favicon set installed.
[ ] OG image installed.
[ ] Meta tags and canonical added.
[ ] Sitemap and robots set for production.
[ ] Analytics / privacy configured.
[ ] Forms protected against spam.
[ ] Error / success form states implemented.
[ ] 404 page uses brand system.

## Quality
[ ] WCAG AA contrast checked.
[ ] Lighthouse reviewed.
[ ] No broken links.
[ ] No placeholder copy.
[ ] Page titles unique.
[ ] Social preview tested.
